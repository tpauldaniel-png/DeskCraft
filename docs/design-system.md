# DeskCraft Design System

## Brand Direction
DeskCraft uses warm modern minimalism with deep navy, warm neutral surfaces with Inter typography.

Tagline: "Build a workspace that work for you."

## Colors

| Token | Value | Usage |
|---|---|---|
| Primary | #16324f | Main button and active states |
| Background | #faf8f4 | Main page background |
| Card | #ffffff | Cards and form surfaces |
| Secondary | #ede7de | Supporting surfaces |
| Muted text | #667085 | Description and helper text |
| Destructive | #b42318 | Errors and delete actions |
| Brand Warm | #c58a45 | Decorative highlights |


## Typography

 - Font-family:  Inter
 - Page-title: text-3xl font-bold
 - Section-title: text-2xl font-semi-bold
 - Card-title: text-lg font-semi-bold
 - Body-text: text-base
 - Supporting-text: text-sm text-muted-foreground


 ## Layout

 - Maximum content width: 80rem
 - Mobile page padding: 1rem
 - Tablet page padding: 1.5rem
 - Desktop page padding: 2rem
 - Section spacing: 4rem
 - Default radius: 0.75rem
